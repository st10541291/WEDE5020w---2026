## Project Overview

A five-page website for **Sipho's Custom Carpentry**, a small custom furniture business based in Khayelitsha, Cape Town. The site moves the business from informal social media selling (Facebook, WhatsApp statuses, TikTok) to a professional, trustworthy digital presence with a permanent portfolio, clear service descriptions, and a formal quote-request system.

The website targets homeowners in Khayelitsha and surrounding Cape Town areas, as well as landlords needing durable built-in cupboards for rental properties.

---

## Website Goals and Objectives

### Goals
- Shift from informal social media sales to a professional, trustworthy digital presence.
- Attract larger, higher-paying contracts (estate agents, homeowners doing full renovations).

### Key Performance Indicators (KPIs)
- **KPI 1:** Generate at least **5 professional quote requests per month** via the enquiry form.
- **KPI 2:** Reduce time spent explaining pricing over WhatsApp by providing a clear, detailed Services page.

---

## Key Features and Functionality

### Core Pages
- **Home** (`index.html`) — Hero image, welcome intro, three service preview cards, call-to-action.
- **About** (`about.html`) — Sipho's story, mission, vision, founder photo.
- **Services** (`services.html`) — Detailed service list, Melamine vs Solid Wood comparison, portfolio gallery, live search filter.
- **Enquiry** (`enquiry.html`) — Full quote-request form with validation and cost estimate response.
- **Contact** (`contact.html`) — Contact details, business hours, general contact form, interactive map with two locations.

### Interactive Features (Part 3)
- **Accordion** on Services page — expandable material explanations.
- **Gallery Lightbox** on Services page — click any portfolio image to enlarge it.
- **Live Search Filter** on Services page — filters service cards as the user types.
- **Enquiry Form Validation** — inline error messages + estimated cost response based on furniture type and material.
- **Contact Form** — validation + `mailto` email compilation.
- **Interactive Leaflet Map** — two markers (Khayelitsha workshop + Cape Town CBD service hub).

### SEO Implementation (Part 3)
- Unique `<title>` tags and meta descriptions on every page.
- Targeted keywords: "carpenter Khayelitsha", "custom kitchen cabinets Cape Town", "built-in wardrobes Cape Town".
- Descriptive image filenames and alt text.
- `robots.txt` and `sitemap.xml` in the project root.
- Mobile-friendly responsive design.
